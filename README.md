# ProjetoSoftexForms
 Este projeto é um formulário web para cadastro de dados pessoais e endereço, com aplicação de cupom de desconto e resumo de compra, desenvolvido em HTML, CSS e JavaScript.  
Funcionalidades
Formulário de Dados Pessoais e Endereço:
Validação dos campos (nome, CPF, telefone, CEP, estado, etc.) antes do envio.
Os dados são salvos no localStorage do navegador.
Resumo da Compra:
Exibe o valor do produto e opções de pagamento.
Cupom de Desconto:
Permite aplicar cupons de desconto (DESCONTO10, DESCONTO20, DESCONTO50).
O valor total é atualizado conforme o cupom aplicado.
Garantia e Segurança:
Informações sobre garantia e segurança dos dados.
Estrutura de Arquivos
Como Usar
Abra o arquivo index.html em um navegador.
Preencha todos os campos do formulário e clique em AVANÇAR.
Para aplicar um cupom, clique em "Aplicar cupom de desconto", insira o código e clique em Aplicar.
O valor total será atualizado e o cupom salvo no navegador.
Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Observações
Os dados do formulário e o cupom são armazenados localmente no navegador usando localStorage.
Para mais informações sobre validação e armazenamento, consulte os arquivos formulario.js e desconto.js.
Explicações sobre operadores e métodos podem ser encontradas em OperadorNot.txt e Json.txt.
